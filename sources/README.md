## Source Precedence

When sources contain conflicting information, use the following approach:

1. **Original records** for dates, awards, credentials, and documented events.
2. **Current founder-authorized publications** for Ela Hersberger's professional identity and artistic philosophy.
3. **Official Masterpiece Artwork publications** for company information and artwork offerings.
4. **Independent publications** for external coverage, reviews, and commentary.
5. **Historical repository versions** for documenting how the artistic philosophy and professional positioning evolved.

No source is automatically authoritative for every type of claim.

## Source Documentation Standards

Each source record should include, when available:

- Source title.
- Author or issuing organization.
- Publication date.
- Original URL or document reference.
- Date accessed, where relevant.
- Type of source.
- Specific claims supported by the source.
- Notes about limitations or uncertainty.

## Accuracy & Attribution

- Do not invent citations, publications, or professional recognition.
- Do not present founder-authored statements as independent verification.
- Distinguish documented achievements from future professional goals.
- Preserve historical sources when professional positioning changes.
- Correct outdated information when supported by newer authoritative records.
- Respect copyright and publication permissions.
